# Frontend

주 담당: 박지우

## 기술
- React
- JavaScript
- Styled Components
- React Router
- REST API
- WebSocket(STOMP)
- 반응형 웹

## 주요 화면/기능
- 로그인 / 회원가입
- 상품 목록 / 상세 / 등록
- 상품 상태 등급 / 상세설명
- 이미지 업로드
- 예약 경매 생성
- READY / OPEN / ENDED 상태 표시
- 수동입찰 / 자동입찰 설정
- 자동입찰 설정/변경 확인 UI: maxAmount 표시
- 현재 가격구간의 서비스 입찰단위와 다음 최소 입찰가 표시
- 자동입찰이 서비스 입찰단위표에 따라 필요한 최소금액만 올린다는 안내
- 최대금액 부근에서는 정규 입찰단위보다 작은 차이로 마지막 자동입찰이 형성될 수 있다는 사전 안내
- 입찰 최종 확인 UI
- 실시간 현재가
- 낙찰 후 거래 진행 / 포기
- 거래 완료 요청 / 상대방 확인
- 재경매
- 신뢰점수
- 브라우저 Push 권한/구독
- 앱 내부 알림센터
