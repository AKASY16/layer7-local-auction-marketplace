# Frontend

주 담당: 박지우

## 기술
- React
- JavaScript
- Styled Components
- React Router
- REST API
- WebSocket(STOMP)
- 반응형 웹

## 주요 화면/기능
- 로그인 / 회원가입
- 상품 목록 / 상세 / 등록
- 상품 상태 등급 / 상세설명
- 이미지 업로드
- 예약 경매 생성
- READY / OPEN / ENDED 상태 표시
- 수동입찰 / 자동입찰 설정
- 입찰 최종 확인 UI
- 실시간 현재가
- 낙찰 후 거래 진행 / 포기
- 거래 완료 요청 / 상대방 확인
- 재경매
- 신뢰점수
- 브라우저 Push 권한/구독
- 앱 내부 알림센터
