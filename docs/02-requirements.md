# 요구사항 및 기능 정의

## 사용자

- 회원가입 / 로그인
- 닉네임 서비스 전체 UNIQUE
- 회원탈퇴 시 물리 삭제 대신 `WITHDRAWN`
- ACTIVE 상품, READY/OPEN 판매경매, OPEN 경매 현재 선두/ACTIVE AutoBid, 진행 중 Trade 의무가 있으면 탈퇴 불가
- 지역 설정: MVP에서는 시·군·구
- 내 판매 / 입찰 / 낙찰 내역 확인
- 신뢰점수 표시

## 상품

- 일상·생활용품 중심 상품 등록
- Category code: DIGITAL / HOME_APPLIANCE / FURNITURE / LIVING_KITCHEN / FASHION / BEAUTY / SPORTS_LEISURE / HOBBY_GAME / BOOK_MEDIA / ETC
- 이미지 업로드: MVP 1~10장, JPEG/PNG/WebP, 파일당 최대 10MB
- 상품 지역은 등록 당시 판매자의 현재 지역을 snapshot으로 저장하며, 이후 사용자가 지역을 변경해도 기존 상품 지역은 유지
- 지역별 조회 / 검색
- 상품 상태 등급
  - `UNOPENED`: 미개봉
  - `LIKE_NEW`: 거의 새것
  - `GOOD`: 양호
  - `FAIR`: 사용감 있음
  - `DAMAGED`: 하자 있음
  - `NEEDS_REPAIR`: 수리 필요
- `conditionDescription` 필수: 흠집, 파손, 기능 이상, 구성품 누락 등 상세 설명
- 입찰 발생 전 상품 정보 수정 가능
- 한 번이라도 입찰이 발생한 Product는 과거 경매 의미 보존을 위해 이후에도 기존 핵심정보와 상태정보 잠금
- 이후 판매자는 1회 200자 이내의 `내용 추가`만 append 방식으로 등록

## 경매

- 시작 가격
- 예약 시작 시간
- 종료 시간
- 상태: `READY / OPEN / ENDED / CANCELED`
- 수동 입찰
- 자동 입찰
- 자동입찰 설정: 최대 입찰 가격(maxAmount)
- 가격 상승폭은 사용자/판매자가 정하지 않고 서비스 공통 가격구간별 입찰단위표로 자동 계산
- 현재가 구간에 따라 수동입찰의 다음 최소 유효 금액과 자동입찰의 다음 금액을 동일 정책으로 계산
- 시작가, 수동입찰 금액, AutoBid maxAmount는 모두 해당 가격구간의 유효 단위에 맞아야 함
- 유효하지 않은 금액은 서버에서 거절
- 자동입찰 설정/변경 전 현재 가격구간의 단위, 다음 최소 입찰가, maxAmount를 안내하고 사용자 확인을 받음
- AutoBid는 경매가 열려 있는 동안 계속 실행되지 않고, 입찰/설정 변경 이벤트가 발생했을 때만 계산
- AutoBid 설정/변경은 즉시 경쟁에 참여하며, Bid 0건에서 첫 AutoBid가 설정되면 startPrice의 실제 AUTO Bid가 생성됨
- 현재 선두가 아닌 AutoBid가 자신의 maxAmount로 다음 유효 입찰가를 만들 수 없으면 EXHAUSTED
- 입찰 직전 금액과 철회 불가 안내
- 마감 직전 입찰에 따른 자동 연장 없음
- 입찰 가능 여부는 클라이언트 표시시간이 아닌 서버시간 기준
- `startAt <= now < endAt`에서만 입찰 가능
- Scheduler 상태 반영이 늦더라도 endAt 이후 입찰은 거절

## 낙찰 후 거래

- 낙찰자는 경매 `endAt` 기준 24시간 안에 거래 진행 또는 포기 선택
- 거래 진행 / 포기 / 미응답 상태 관리
- `IN_PROGRESS` 이후 판매자 또는 구매자 중 한 명이 거래 완료 요청
- 상대방이 확인해야 `COMPLETED`
- 상대방이 미완료로 판단하면 `IN_PROGRESS` 복귀
- 차순위 승계 없음
- 거래 실패 시 판매자 선택으로 새 Auction 생성

## 신뢰점수

- 초기값 0
- 정상 거래 완료: 판매자 +2 / 구매자 +2
- 낙찰 포기: 구매자 -5
- 24시간 미응답: 구매자 -10
- MVP에서는 음수 허용, 별도 상·하한 없음

## 알림

브라우저 Web Push + 앱 내부 알림을 사용합니다.

주요 이벤트:
- 상회입찰
- 자동입찰 한도 소진
- 낙찰/유찰
- 낙찰 응답 요청
- 응답 기한 임박
- 거래 진행/포기/미응답
- 상품 내용 추가
- 완료 요청
- 최종 거래 완료
