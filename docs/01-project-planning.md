# 프로젝트 기획

## 1. 현재 방향과 문제 정의

LAYER7은 전국 수집품 대상 경매 플랫폼으로 전환합니다. 2026-10-29 결정은 [결정 로그](04-decisions.md)에 남기며, 이전 지역 중고거래 기획은 Git 이력으로 보존합니다.

수집품은 이름이 같아도 판본·언어·상태 등으로 거래 대상이 달라질 수 있습니다. 구매 수요가 흩어져 있고 참여 가능한 시간이 다르면 판매자는 적절한 마감 시각을 정하기 어렵습니다. 이 문제의 실제 효과와 한계는 데이터·비교 실험으로 확인합니다.

## 2. 최종 시연 목표

2026-10-29 기준 3~4주 후 최종 시연에서는 다음을 중심으로 보여줍니다.

1. 구매 희망과 상품 동일성 매칭, 수요 집계·참여 가능 시간 기반 마감 편성.
2. 최소 경매 MVP 위에서 이 기술을 연결한 흐름과 재현 가능한 비교 실험.

이상입찰 탐지는 2026-10-31 보류했습니다([보류 계획](later/anomaly-bid-detection.md)).

논문 원문에서 확인한 내용과 자체 설계를 구분합니다. 관심 사용자 수는 예상 입찰자 수가 아닙니다.

## 3. 핵심 사용자와 최소 흐름

- 구매자: 원하는 수집품·허용 조건·참여 가능 시간을 등록하고 경매에 참여합니다.
- 판매자: 상품과 매칭되는 수요·마감 후보·추천 근거를 확인하고 경매를 만듭니다.

테스트 계정 → 이미지 업로드·상품 등록/이미지 표시 → 경매 생성/조회 → 수동입찰·이력 → 종료·낙찰 확정이 최소 경매 흐름입니다. 기존 입찰 엔진의 정합성을 유지합니다. 상세 범위는 [요구사항](02-requirements.md), 검증은 [P1 실험 계획](p1/experiments.md)을 따릅니다.

## 4. 범위와 미결정 사항

상품의 최초 이미지 업로드·등록·표시는 최소 MVP에 포함합니다. 등록 후 이미지 추가·삭제·재정렬과 정리 배치, HTTP 요청 멱등 기능, 자동입찰·Trade·신뢰점수 변경·배송·결제·채팅·범용 Push는 후순위입니다. WebSocket과 실시간 ML 추론은 선택입니다. 전국 탐색 전환과 기존 지역 데이터 삭제는 별개이며 현재 지역 계약을 유지합니다.

상품군·카탈로그 출처·정확한 발표일·논문 지표/수식·세부 API/ERD는 미정입니다. 개인별 책임은 각 이슈의 Assignees와 [협업 규칙](00-team-and-collaboration.md)을 따릅니다. 한 상품군으로 시작하는 설계를 검토하며, 특정 카테고리를 확정한 것으로 기록하지 않습니다.
