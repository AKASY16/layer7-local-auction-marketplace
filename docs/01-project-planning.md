# 프로젝트 기획

## 1. 문제 정의

지역 기반 중고거래에서는 같은 제품이라도 사용 기간, 상태, 구성품 등에 따라 실제 가치가 달라 적정 판매가를 정하기 어렵습니다. 판매자와 구매자가 반복적으로 가격을 협상해야 하는 경우도 있으며, 인기 상품은 먼저 게시물을 확인하거나 연락한 사용자에게 거래 기회가 집중될 수 있습니다.

또한 거래 조건을 합의한 이후의 미응답·취소 등으로 거래가 무산될 수 있어, 낙찰 이후의 거래 절차와 우선권을 어떻게 관리할지도 함께 고려합니다.

> 경매 기능만으로 허위매물·노쇼·거래 취소 같은 모든 신뢰 문제를 해결한다고 보지는 않습니다. 해당 문제는 거래 절차와 정책을 통해 별도로 다룹니다.

## 2. 해결 방향

기존 지역 기반 중고거래에 **제한시간 경매**를 결합한 웹 애플리케이션을 개발합니다.

- 주요 거래 대상: 일상·생활용품
- MVP 지역 단위: 시·군·구
- 판매자가 상품, 시작가, 예약 시작 시간, 종료 시간 설정
- 입찰 상승폭은 서비스 공통 가격구간별 입찰단위표로 자동 결정
- 구매자가 수동 또는 자동 입찰 참여
- 현재 가격과 경매 상태 실시간 확인
- 경매 종료 후 낙찰 결과 확정
- 낙찰자의 거래 의사 확인 → 거래 진행 → 거래 완료·포기·미응답 관리
- 거래 실패 시 차순위 승계 없이 판매자 선택으로 새 경매 생성

## 3. 핵심 사용자

### 판매자
- 지역 내 중고물품을 판매하려는 사용자
- 여러 구매자의 수요를 통해 판매 가격을 형성하려는 사용자

### 구매자
- 지역 내 중고물품을 찾는 사용자
- 단순 선착순이 아닌 경매 방식으로 구매 기회를 얻으려는 사용자

## 4. 프로젝트 특징

- 지역성
- 제한시간 경매
- 예약경매
- 실시간 현재가·상태 전달
- 수동/자동입찰
- 낙찰 후 거래 상태 관리
- 사용자 신뢰점수
- 주요 경매·거래 이벤트 푸시 알림
- 과거 낙찰 데이터 기반 확장 가능성
