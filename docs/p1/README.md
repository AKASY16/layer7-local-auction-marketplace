# P1 — 최종 시연 범위

2026-10-29 방향 전환(#60). 현재 요구사항의 원본은 [02-requirements.md](../02-requirements.md)입니다. 이 문서는 목표와 작업 연결을 설명하며 구현 완료를 뜻하지 않습니다.

## 목표와 범위

전국 수집품 경매의 수요 기반 매칭·마감 편성을 3~4주 후 최종 시연에서 설명·검증합니다.

| 영역 | 필수 결과 | 작업 |
|---|---|---|
| 최소 경매 | 최초 이미지 업로드·상품 등록/표시·경매 생성/상세·수동입찰·이력·종료·낙찰 | #63~#65, #47. 기존 입찰 엔진 유지 |
| 수요·편성 | 구매 희망·가능 시간·상품 동일성 매칭·집계·마감 추천·근거·화면 | #62, #70~#73 |
| 검증 | 합성 시나리오·독립 평가·응답 성능·통합 시연 | #75, #76 |

이상입찰 탐지는 2026-10-31 보류했습니다. 계획은 [보류 계획](../later/anomaly-bid-detection.md)으로 옮겼습니다.

자동입찰·Trade·신뢰점수 변경·범용 Push·배송·결제·채팅·Refresh·등록 후 이미지 편집/정리 배치·HTTP 요청 멱등 기능은 후순위입니다. WebSocket·실시간 ML·임베딩은 선택입니다.

## 설계에서 지킬 경계

- 최초 상품 등록은 기존 1~10장 이미지 정책을 적용합니다. 업로드 URL → 파일 PUT → 상품에 연결 → 이미지 표시를 포함하고 이미지 없는 등록으로 대체하지 않습니다.
- HTTP 요청 멱등 기능과 C09 테스트는 함께 후순위입니다. P1에서 키는 필수가 아니고 전달되어도 무시합니다. 종료 중복 실행 방지(#47)는 필수입니다.

- 입찰은 Auction 락 후 서버 시각으로 판정하며 Bid에 같은 시각을 기록합니다.
- 정확/조건부/유사 매칭을 구분하고 유사 상품을 정확 일치 수요에 합산하지 않습니다. 관심자 수는 예상 입찰자 수가 아닙니다.
- 개별 구매 희망 가격 상한은 공개하지 않습니다. 편성 점수식은 자체 설계이며 효과는 독립 비교 실험으로 확인합니다.

## 선행 작업과 미결

상품군·카탈로그·동일성·수요/시간 계약은 #62에서 확정합니다. 정확한 발표일·최종 API/ERD는 미정입니다. 개인별 책임은 각 이슈의 Assignees와 [협업 규칙](../00-team-and-collaboration.md)을 따릅니다. 기존 지역 필드·스키마를 전국 전환이라는 이유로 제거하지 않습니다.

범위가 큰 구현 이슈는 실제 계약을 정한 뒤 작은 PR로 나눕니다. 현황은 [작업 안내](../task-board.md)와 [마일스톤](https://github.com/AKASY16/layer7-local-auction-marketplace/milestone/2)에서 확인합니다.
