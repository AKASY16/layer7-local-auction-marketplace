# P1 — 최종 시연 범위

2026-10-29 방향 전환(#60). 현재 요구사항의 원본은 [02-requirements.md](../02-requirements.md)입니다. 이 문서는 목표와 작업 연결을 설명하며 구현 완료를 뜻하지 않습니다.

## 목표와 범위

전국 수집품 경매의 두 기술을 3~4주 후 최종 시연에서 설명·검증합니다.

| 영역 | 필수 결과 | 작업 |
|---|---|---|
| 최소 경매 | 상품·경매 생성/상세·수동입찰·이력·종료·낙찰 | #63~#65, #47. 기존 입찰 엔진 유지 |
| 이상입찰 | 온라인 특성·위험 점수·오탐 감소·데이터 부족·근거·버전, 커밋 후 분석, 관리자 화면 | #61, #66~#69 |
| 수요·편성 | 구매 희망·가능 시간·상품 동일성 매칭·집계·마감 추천·근거·화면 | #62, #70~#73 |
| 검증 | 공개 데이터 비교·합성 시나리오·독립 평가·응답 성능·분석 지연·통합 시연 | #74~#76 |

자동입찰·Trade·신뢰점수 변경·범용 Push·배송·결제·채팅·Refresh·범용 이미지 관리는 후순위입니다. WebSocket·실시간 ML·MRF/LOF·임베딩은 선택입니다.

## 설계에서 지킬 경계

- 입찰은 Auction 락 후 서버 시각으로 판정하며 Bid에 같은 시각을 기록합니다. 분석은 성공 커밋 후 별도 처리합니다.
- 위험 점수는 확률이나 부정 확정 판정이 아닙니다. 자동 차단하지 않고 오탐 감소·최소 표본·데이터 부족을 포함합니다.
- 논문에서 확인한 지표·가중치·PFP와 자체 규칙을 구분합니다. LSS 원문 미확보 상태이므로 상세 구현은 #61 확인 후 확정합니다.
- 정확/조건부/유사 매칭을 구분하고 유사 상품을 정확 일치 수요에 합산하지 않습니다. 관심자 수는 예상 입찰자 수가 아닙니다.
- 개별 구매 희망 가격 상한은 공개하지 않습니다. 편성 점수식은 자체 설계이며 효과는 독립 비교 실험으로 확인합니다.

## 선행 작업과 미결

원문·온라인 특성·이벤트/권한 계약은 #61, 상품군·카탈로그·동일성·수요/시간 계약은 #62에서 확정합니다. 정확한 발표일·개인별 새 분업·최종 API/ERD는 미정입니다. 기존 지역 필드·스키마를 전국 전환이라는 이유로 제거하지 않습니다.
