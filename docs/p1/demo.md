# P1 통합 시연 목표

아래는 #76에서 완성할 목표 시나리오이며 아직 실행 가능한 절차가 아닙니다. 현재 동작하는 MVP 실행은 [기존 시연 문서](../demo.md)를 참조합니다.

1. 판매자가 이미지를 1장 이상 업로드해 상품을 등록하고 이미지 표시를 확인합니다.
2. 같은 판매자가 일반 경매와 타임 경매를 하나씩 만듭니다. 타임 경매는 홈의 "곧 시작" 목록에 시작 시각과 함께 보입니다.
3. 구매자들이 타임 경매 상품을 관심상품으로 등록합니다. 예고 기간에는 입찰이 거절됩니다.
4. 시작 시각에 관심상품 등록자가 앱 내부 알림을 받고 경매 상세로 들어옵니다.
5. 여러 구매자가 수동입찰하고, 다른 브라우저 화면이 WebSocket으로 새로고침 없이 바뀌는 것을 확인합니다.
6. 마지막 1분 안에 입찰해 종료 시각이 "판정 시각 + 1분"으로 늘어나고 연장 횟수가 화면에 바로 반영되는 것을 확인합니다.
7. 경매가 종료되면 낙찰/유찰과 finalized를 확인합니다. Trade·결제·배송은 포함하지 않습니다.
8. 연장·종료 경합 테스트 결과와 입찰 성능 측정 결과를 설명합니다.

## 완료 기준

- 데이터 준비·실행 순서·계정·환경과 정리 절차를 문서화해 재시연할 수 있습니다. 시연용 타임 경매는 예고 기간을 기다리지 않도록 시작 시각을 조정하는 방법을 함께 적습니다.
- 화면·API·DB·WebSocket·실제 입찰·낙찰이 연결되며 예고 기간 입찰 거절, 연결이 끊겼다가 다시 붙는 경우도 확인합니다.
- 가짜 값·미구현 부분을 표시합니다. 시뮬레이션 수치를 서비스 성과로 제시하지 않습니다.
- 정확한 발표일은 미정입니다. 시연 주관자와 각자 책임은 #76의 Assignees와 담당·책임 본문을 따릅니다.
