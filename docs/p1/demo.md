# P1 통합 시연 목표

아래는 #76에서 완성할 목표 시나리오이며 아직 실행 가능한 절차가 아닙니다. 현재 동작하는 MVP 실행은 [기존 시연 문서](../demo.md)를 참조합니다.

1. 테스트 구매자들이 같은 수집품에 서로 다른 판본·허용 상태·가능 시간으로 구매 희망을 등록합니다.
2. 판매자가 상품을 등록하고 정확/조건부/유사 수요와 추천 마감 후보·대안·근거를 확인합니다.
3. 선택한 후보로 경매를 만들고 정상 사용자의 수동입찰과 이력을 확인합니다.
4. 사전 정의한 의심 입찰과 필요한 과거 이력을 합성 시나리오로 실행합니다. 실제 입찰 정책을 지킵니다.
5. 관리자가 커밋 후 분석의 대기/완료·위험 점수 변화·근거·버전·데이터 부족을 확인합니다.
6. 경매가 종료되면 낙찰/유찰과 finalized를 확인합니다. Trade·결제·배송은 포함하지 않습니다.
7. 공개 데이터와 합성 시나리오의 비교 결과·오탐·한계, 마감 편성 평가, 입찰 성능·분석 지연을 구분해 설명합니다.

## 완료 기준

- 데이터 준비·실행 순서·계정 권한·환경과 정리 절차를 문서화해 재시연할 수 있습니다.
- 화면·API·실제 입찰·분석·낙찰이 연결되며 관리자 접근 거절·분석 실패·수요 없음도 확인합니다.
- 가짜 값·합성 시나리오·공개 데이터·미구현 부분을 표시합니다. 외부 논문 수치를 자체 성과로 제시하지 않습니다.
- 남은 정확한 발표일·상품군·새 분업·실험 설정은 해당 설계 이슈에서 확정합니다.
