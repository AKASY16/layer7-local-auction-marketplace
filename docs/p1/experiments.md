# P1 실험과 측정 기준

이 문서는 앞으로 수행할 실험의 기준입니다. 아직 성능 수치나 검증 결과는 없습니다. 기능 완료와 효과 검증을 구분하고 자세한 방법은 #61·#62·#74·#75에서 확정합니다.

| 실험 | 입력과 비교 | 보고할 결과 |
|---|---|---|
| 오프라인 분류 | 원출처·레이블 의미를 확인한 공개 데이터, 기준 모델/Random Forest (XGBoost 선택) | Precision·Recall·F1·PR-AUC·FPR·추론 지연. 실제 부정 확정/온라인 LSS 성능으로 일반화하지 않음 |
| 온라인 탐지 | 현재 시점까지의 실제 입찰 경로와 사전 정의한 합성 정상/의심 이력 | 규칙/원문 적용 모델·오탐 감소 전후, 데이터 부족·탐지 지연·근거 |
| 상품 매칭 | 독립 라벨링한 상품·구매 희망 쌍, 키워드 기준/식별·속성 매칭 | 정확/조건부/유사별 Precision·Recall·F1과 경계 사례 |
| 마감 편성 | 임의·고정·추천 시각, 별도 참여 행동 가정 또는 사용자 실험 | 참여·경쟁·유찰 지표와 가정. 점수 최적화 자체를 실제 효과로 해석하지 않음 |

## 재현과 정보 누수

- 합성·공개·실사용 데이터를 구분하고 원출처·버전·행/사용자/경매 단위·레이블 생성 방법을 기록합니다.
- 같은 입찰자·경매·시간 이력의 교차 의존성을 확인하고 평가 질문에 맞는 분할을 선택합니다. 전처리·튜닝은 훈련 데이터 안에서 수행합니다.
- 진행 중에는 미래 낙찰 결과나 종료 후 특성을 사용하지 않습니다. 공개 데이터의 계산된 특성만으로 원시 이벤트 기반 모델을 동일 조건 평가했다고 주장하지 않습니다.
- 시드·코드 버전·설정·임계값 선택 방법·실행 명령·결과와 실패/오탐 사례를 보관합니다.

## 기존 입찰과 성능

기존 C02·마감 경계 회귀와 #47의 C08을 실제 MySQL에서 확인합니다. 분석 도입 전후를 같은 조건(환경·경매 수·요청 수·동시성·데이터·반복)으로 비교합니다. 입찰 응답의 p50/p95/p99·오류·락 대기와 커밋 후 분석 반영 지연을 따로 기록합니다. 환경·단위·측정 구간을 명시하며 테스트 통과 횟수를 처리량으로 표현하지 않습니다.
