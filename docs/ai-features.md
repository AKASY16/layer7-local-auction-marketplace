# AI 기능 검토

AI 기능은 핵심 거래를 대신하지 않고 판매자의 등록/경매 설정과 구매자의 탐색/판단을 보조합니다.

## 1. AI 경매 설정 도우미
- 시작가 또는 범위
- 경매 시간
- 추천 근거
- 과거 낙찰 데이터 + 규칙 기반 계산 활용
- 최종 조건은 판매자가 확정
- 입찰 단위는 서비스 공통 가격단위표로 고정되므로 추천 대상이 아님

## 2. AI 상품 상태·사진 검수
- 전체 사진
- 모델명/라벨
- 흠집·파손 부위
- 구성품
- 작동 여부
- 추가 촬영 권장

AI가 진품 여부나 실제 품질을 보증하지 않습니다.

## 3. AI 입찰 가격 가이드
- 유사 상품 낙찰 범위
- 평균 / 중앙 낙찰가
- 현재 입찰가의 상대적 위치
- 비교 거래 건수
- 데이터 부족 시 결과 생성 자제

## 4. AI 자연어 상품 검색
자연어를 지역·상품·가격·종료시점 등의 실제 검색조건으로 변환합니다.

## 데이터 의존성

| 기능 | 필요한 데이터 | 시연 시점 사용 가능성 |
|---|---|---|
| 1. 경매 설정 도우미 | 서비스 내 과거 낙찰 데이터 | 낮음. 오픈 직후에는 낙찰 이력이 거의 없음 |
| 2. 상품 상태·사진 검수 | 등록 시 올린 사진 | 높음. 서비스 데이터 없이 동작 |
| 3. 입찰 가격 가이드 | 유사 상품 낙찰 데이터 | 낮음. "데이터 부족 시 생성 자제" 규칙 때문에 대부분 결과가 나오지 않음 |
| 4. 자연어 상품 검색 | 검색 질의와 기존 검색 조건 | 높음. 서비스 데이터 없이 동작 |

1·3번은 낙찰 데이터가 쌓여야 의미 있는 결과가 나옵니다. 외부 시세 데이터나 시드 데이터로 보완할 수 없다면, 대표 기능은 2·4번을 우선 검토합니다.

## 미결
대표 AI 기능 2~3개는 아직 최종 선정하지 않았습니다.
