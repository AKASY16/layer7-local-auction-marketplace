# AI 기능 검토

AI 기능은 핵심 거래를 대신하지 않고 판매자의 등록/경매 설정과 구매자의 탐색/판단을 보조합니다.

## 1. AI 경매 설정 도우미
- 시작가 또는 범위
- 최소 입찰 단위
- 경매 시간
- 추천 근거
- 과거 낙찰 데이터 + 규칙 기반 계산 활용
- 최종 조건은 판매자가 확정

## 2. AI 상품 상태·사진 검수
- 전체 사진
- 모델명/라벨
- 흠집·파손 부위
- 구성품
- 작동 여부
- 추가 촬영 권장

AI가 진품 여부나 실제 품질을 보증하지 않습니다.

## 3. AI 입찰 가격 가이드
- 유사 상품 낙찰 범위
- 평균 / 중앙 낙찰가
- 현재 입찰가의 상대적 위치
- 비교 거래 건수
- 데이터 부족 시 결과 생성 자제

## 4. AI 자연어 상품 검색
자연어를 지역·상품·가격·종료시점 등의 실제 검색조건으로 변환합니다.

## 미결
대표 AI 기능 2~3개는 아직 최종 선정하지 않았습니다.
