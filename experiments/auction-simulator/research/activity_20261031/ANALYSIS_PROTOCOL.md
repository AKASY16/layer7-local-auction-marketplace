# 원자료 분석 규칙 — 정책 결과 확인 전

- 원본 CSV/PDF는 이동 전후 SHA256 일치. 원래 위치·새 위치는 relocation manifest 기록.
- 전체 CSV 파싱·5열 스키마·행수·고유값·결측·정확 중복·원래 시각 순서 검사.
  고유 활동 사용자 주 분석은 원행을 유지한 날짜×시간의 distinct visitor다.
  정확 중복 제거는 보조 진단이며 같은 기록이 오류였다고 단정하지 않는다.
- 공식 Unix millisecond timestamp는 UTC 기준 분석 시계로 변환한다. 이용자 현지
  시간대/지역이 별도로 확인되지 않으면 절대 현지 시각 추천 근거로 쓰지 않는다.
  item properties/category tree와 식별 가능한 라벨이 없으면 수집품 하위군을 만들지 않는다.
- 첫·마지막 경계 주를 제외한 Monday–Sunday 완전 달력 주 중 처음 floor(2/3)를
  학습, 나머지를 평가로 고정한다. 주 경계/기간 선택에는 정책 성과를 사용하지 않는다.
- 기본 프로파일: 날짜-시간별 고유 활동 사용자 수의 weekday×hour 평균, 전체168셀
  평균1. 뷰/거래 이벤트 및 고유 구매자·거래ID 분포는 별도. pooled unique와
  user-date-hour 지표를 구분한다. 하위30분의 독립 관측 정밀도를 주장하지 않는다.
- 날짜별 전체량 제거한 일별 shape 평균도 비교. 주 단위 bootstrap2000회와 weekday
  내 날짜 bootstrap2000회를 고정 난수로 산출한다. 이 구간은 표본 변동이며 logging
  누락·시간대·외적 타당성 불확실성을 해결하지 않는다.
- 소수 방문자 영향: 전체 top0.1%의 이벤트 점유율을 기술하고, 학습 top0.1% ID만
  과거 자료로 정한 제외 민감도를 양 기간에 동일 적용. 이들을 봇이라고 확정하지 않는다.
- 이상 날짜: 학습 일별 고유 사용자 기준 median/MAD robust z>|5| 및 시간셀 기록
  누락을 진단. 자동 삭제·이상일을 정책 성과에 맞춰 선택하지 않는다.
- 재방문: 관측된 다일 방문, 시간 간격, >30min gap의 관측 세션(ASSUMED 기준),
  최초 관측일 기준 우측 검열을 반영한1/7/28일 안의 이후 날짜 재방문을 별도 정의.
  최초 관측을 진짜 가입일로 해석하지 않는다.
- 시간순 학습 프로파일→평가 프로파일 오차와 평가 개별 주의 변동을 보존한다.
  정책 실험은 자료 사용 판정과 방문율/peak/cap 검토 후 별도 사전 고정한다.
