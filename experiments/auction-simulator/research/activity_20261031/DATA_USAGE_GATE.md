# 1단계 자료 사용 판정 (정책 재실험 전)

## 판정

**Retailrocket은 일반 이커머스의 관측 활동 형태·시간순 예측 오차·시간대 이동
민감도에 한해 사용 가능하다. 실제 한국/특정 국가의 절대 종료 시각 근거로는
사용하지 않는다. 수집품 하위군도 식별하지 않는다.**

**Simonsohn 자료는 원문 관계·변수 정의·해석 검토에 사용한다. 원자료가 없어
회귀를 직접 재현하거나 LAYER7의 경쟁 계수를 추정한 것으로 표시하지 않는다.**

## 로컬 원본과 무결성

두 파일은 사용자 지시로 내용 변경 없이 이동했다. 이동 전/후 SHA256을 확인했고
이전 모든 파일의 보호 목록도 먼저 만들었다. 보관 위치:

- CSV: `data/external/activity_profiles/retailrocket/events.csv`
- 새 PDF: `research/papers/simonsohn_2010_revalidation/ebays_crowded_evenings_2010.pdf`

CSV는94,237,913bytes, SHA256
`3745aa83238b1e6d44d8fda209807899f420084398f94ddf745f3cbcfecbf9e7`.
2,756,101행·5열, 고유 visitorid1,407,580개, itemid235,061개다. 공식 카드의
행/이벤트/방문자 수와 일치하지만 게시자 체크섬이 확보되지 않아 파일의 암호학적
출처 인증까지 주장하지 않는다. visitor ID는 실제 사람/계정 수와 같다고 볼 수 없다.

view2,664,312 / addtocart69,332 / transaction22,457. transactionid 결측

로그 오류라고 확정하지 않으며 기본 UA distinct 집계에는 중복 기여하지 않는다.

## 시간·지역·상품 범위

[공식 데이터 카드](https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset)는
timestamp를 Unix timestamp로 설명한다.13자리 값과 기간을 대조해 millisecond로
해석하고 UTC 분석 시계를 사용한다. 실제 관측 범위는2015-05-03 03:00:04.384 UTC
부터2015-09-18 02:59:47.788 UTC다. UTC로 표시할 수 있다는 것과 쇼핑몰 이용자의
현지 시간대를 안다는 것은 다르다. 검토한 공식 설명/로컬 컬럼에서 이용자 국가,
IANA timezone, 지역 구성이 확인되지 않았다. 회사 소재지나 분포의 피크를 이용해
현지 시간대를 추정해 채우지 않는다.

현재 제공 파일에는 itemid만 있고 상품명·카테고리·item_properties/category_tree가
없다. 공식 자료에도 속성/텍스트 익명화가 명시돼 있어 지금의 파일만으로 수집품을
특정할 수 없다. 한국 수집품 경매 입찰의 실측 자료라고 표현하지 않는다.

## 라이선스와 출처 확인 범위

[공식 카드의 검색 캐시](https://www.kaggle.com/retailrocket/ecommerce-dataset/home)에서
**CC BY-NC-SA4.0** 표기를 확인했다(2026-10-31 조회). Kaggle notebook의 Apache
라이선스와 혼동하지 않는다. 직접 카드/API의 HTTP 수집은404였고 로컬에 LICENSE가
동봉되지 않았다. 따라서 공식 카드 표기 확인이라는 증거 범위를 명시한다.

[공식 CC 조건](https://creativecommons.org/licenses/by-nc-sa/4.0/)에 맞춰 원출처·
라이선스·변경 여부를 기록한다. 이번 용도는 비상업 연구다. 배포하는 데이터/적응
프로파일에는 NC/SA 조건을 보존하며, 상업 서비스에 데이터/프로파일을 내장할 권한을
확보했다고 주장하지 않는다. 분석 코드 전체가 자동으로 같은 라이선스라는 뜻도 아니다.
이번 작업은 푸시·공개 재배포·서비스 배포를 하지 않는다.

## 시간순 분리와 왜곡 진단

처음/마지막 경계 주를 제외한19개 완전 달력 주를 사전 규칙대로12주 학습,
7주 평가로 나눴다. 학습2015-05-04≤t<2015-07-27, 평가2015-07-27≤t<2015-09-14.
경계78,174행은 기본 프로파일에서 제외하고 품질 요약에는 유지했다.

전체 상위0.1%(1,408ID)가 이벤트8.075%를 만든다. 가장 많은 ID는7,757이벤트다.
이들을 비정상 사용자라고 확정하지 않는다. 학습 상위0.1%인900ID를 과거에서
고정해 제외한 민감도를 별도로 저장했다. |5MAD|/24시간 관측 누락 진단에서 표시된
날짜는 경계일들이다. 이를 봇/장애로 확정하거나 유리한 날짜만 남기지 않았다.

기본 UA 프로파일은 날짜-시간 distinct visitor 평균이며, 기간 전체 weekday-hour
distinct visitor와 다르다. 학습→평가168셀 RMSE0.05762, TV0.02241,
상관0.99441이다. 이는 같은 익명 쇼핑 자료의 시간적 안정성이며 실제 경매 검증이
아니다. 구매 이벤트 프로파일은 RMSE0.29004로 더 불안정했다. 날짜/주 bootstrap과
개별 평가 주 수치를 모두 보존한다. 세션30분 기준은 분석 정의(ASSUMED)로만 쓴다.
