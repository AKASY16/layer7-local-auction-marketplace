# Retailrocket 검증·활동 프로파일 분석

## 자료 사용 판정

**상대적 활동 형태와 시간대 이동의 스트레스 자료로 사용 가능. 절대 KST 추천의 실측 근거, 한국 수집품 경매 입찰 수요로는 사용 불가.** 공식 설명과 원자료만으로 현지 시간대·국가·수집품 범주를 식별할 수 없다. 판단 후 별도 정책 실험을 진행했으며 좋은 성과를 내는 위상을 한국의 정답으로 선택하지 않는다.

출처·라이선스·이동 경로는 [SOURCES_AND_LICENSE.md](SOURCES_AND_LICENSE.md), 시간 이전의 의미는 [TIME_TRANSFER.md](TIME_TRANSFER.md), 사전 자료 분석 규칙은 [ANALYSIS_PROTOCOL.md](ANALYSIS_PROTOCOL.md)에 있다. 원본은 읽기 전용으로 사용했다.

## 무결성과 스키마

94,237,913 bytes, SHA256 `3745aa83238b1e6d44d8fda209807899f420084398f94ddf745f3cbcfecbf9e7`. 이동 전후 바이트 동일. 제공자 체크섬은 확인하지 못했으므로 암호학적 배포 원본 인증은 아니다. 로컬 행수·이벤트 수·visitor 수가 공식 카드와 일치한다.

| 고유 visitor ID / item ID | 1,407,580 / 235,061 |

| 원파일의 시간 역전 인접 행 | 1,377,377(원본이 비정렬; 재방문 분석만 안정 정렬) |

열은 timestamp(int64), visitorid(int64), event(3종), itemid(int64), transactionid(nullable integer)다. transactionid 결측2,733,644건은 모두 비구매 이벤트이며 구매 이벤트의 ID 결측과 비구매의 잘못된 ID는0건이다. 나머지4열 결측0. 거래 행은 상품 단위이므로 구매 이벤트 수와 주문 수를 바꾸어 쓰지 않는다.

관측 범위는 밀리초 Unix를 UTC로 표시한 **2015-05-03 03:00:04.384 ~ 2015-09-18 02:59:47.788**. UTC 표시가 실제 이용자 생활 시각이라는 뜻은 아니다. +9시간은 같은 순간의 KST 표시일 뿐 생활 패턴의 한국 이전 근거가 아니다. 국가·현지 시각·DST·혼합 지역 구성을 확인할 자료가 없다. 특히 처음/마지막03시 경계나 활동 피크만으로 UTC offset을 역추정하지 않았다.

공급된 events.csv에는 카테고리·상품 의미가 없고 category_tree/item_properties는 제공되지 않았다. 숫자 ID만으로 수집품을 식별할 수 없다. 원본 공개판의 범주 ID가 있더라도 의미 라벨과 검증 없이 수집품이라고 간주할 수 없다.

## 시간 분리와 관측 단위

완전한 월~일19주를 먼저 고정했다. 학습12주: **2015-05-04≤t<2015-07-27**, 평가7주: **2015-07-27≤t<2015-09-14**(UTC). 경계78,174행은 주간 프로파일에서 제외하되 품질 통계에는 남겼다. 미래 평가 자료로 학습 이상사용자 목록/프로파일을 보정하지 않았다.

기본 셀은 날짜별 해당 시간의 distinct visitor 수를 동일 요일의 관측 날짜에 걸쳐 평균한 값이다. 한 사람을 여러 시간 셀에서 셀 수 있으므로 주간 고유 사람 수가 아니다. 전 기간의 요일×시간 pooled unique는 별도 CSV에 저장했고 기본 추정량과 혼용하지 않는다. 조회 이벤트, 거래 상품 행, 고유 구매 visitor, 고유 주문 ID는 각각 별도 분포다. 모든 기본 프로파일은168개 셀 평균1이고 시간 내 상수다. 30분 내부 차이는 추정하지 않았다.

| 관측량 | 학습→평가 TV 거리 | 셀 MAE | 상관 |
| --- | ---: | ---: | ---: |
| 고유 활동 visitor | 0.02241 | 0.04483 | 0.99441 |
| 조회 이벤트 | 0.02423 | 0.04846 | 0.99274 |
| 거래 상품 행 | 0.10392 | 0.20784 | 0.93902 |
| 고유 구매 visitor | 0.08589 | 0.17178 | 0.95420 |
| 고유 주문 ID | 0.08556 | 0.17113 | 0.95350 |

TV는 평균1 배열을 확률 질량으로 바꾼 뒤 0.5*L1 거리다. 기본 활동 형태가 이 자료의 이후 기간에서도 비교적 안정적이라는 뜻이며, 이커머스→경매 또는 해외→한국 이전을 검증한 것은 아니다. 거래 프로파일은 더 희소하고 불확실성이 크다. 학습 기준 활동 피크는 UTC 좌표20시, 평가21시이나 이것을 한국20~21시 또는 원지역20~21시로 해석하지 않는다.

학습 주 단위 재표집2,000회로 각 셀95% 구간을 저장했다. 기본 활동 셀 구간 폭의 중앙값0.1475, 최댓값0.4180이며, 거래 행은0.5257/1.6266이다. 날짜 단위 bootstrap도 요일을 보존해 별도로2,000회 수행했다. 셀 구간은 다중비교 보정한 동시 구간이 아니다. 평가7개 주별 프로파일도 보존해 정책 민감도에 사용하며,7주를 추가 독립 seed로 세지 않는다.

## 소수 이용자와 날짜 영향

날짜 bootstrap의 기본 UA 셀 구간 폭 중앙값/최댓값은0.1443/0.4014다. 같은 ID가 주를 넘어 반복될 수 있고 단일 쇼핑몰의12주 표본이므로 다른 국가·사이트의 모집단 불확실성을 포괄하는 구간은 아니다.

한 날짜씩 제외하면 기본 프로파일의 TV 변화는 최대0.00667(2015-07-26), 한 주씩 제외하면 최대0.01054(마지막 학습 주)였다. 최대 영향 날짜도 임의로 제거하지 않았다. 이는 개별 날짜가 전체 형태를 지배하는지 보는 진단이며 date_influence.csv에 전체 값을 보존했다.

전체 상위0.1%(1,408 ID)는 이벤트8.075%를 차지하고 최다 ID는7,757건이다. 자동화 여부는 식별하지 못했으므로 확정적인 봇 라벨을 붙이지 않는다. 학습 자료에서만 선정한 상위0.1%(900 ID)를 학습·평가에서 제외한 보조 프로파일을 만들었다. 이때 학습 UA 형태의 원본 대비 TV는0.00428, 학습→평가 TV는0.02341이다. 특정 소수의 이벤트 반복이 기본 distinct visitor 형태를 지배한다는 증거는 약하다.

정확한 조회 중복 제거 전후 차이는 극히 작다(학습→평가 TV0.02423 유지). 하루의 전체 규모를 같게 가중하는 진단은 기본 UA 대비 TV0.04691로, 날짜별 규모 가중이 완전히 무관하지는 않다. 모든 날짜를 '이상'으로 지우지 않고 실제 주별 변동을 별도 조건으로 남겼다.

학습 기간의 중앙값·MAD로 고정한5MAD 검사와 관측 시간 수 검사는 처음21시간·마지막3시간인 경계 날짜만 표시했다. 내부 날짜에서 이 규칙으로 식별된 이상은 없다. 이는 장애/봇이 없다는 보증이 아니라 현재 진단으로 추가 제외 근거를 얻지 못했다는 뜻이다.

## 재방문

다른 날짜에도 관측된 ID143,769, 30분 초과 공백으로 나눈 관측 세션1,761,675개다. 세션 경계30분은 ASSUMED 관례이며 원 엔진의 방문/재입찰 간격을 이 값에 맞춰 바꾸지 않는다. 양의 이벤트 간격 중앙값137.295초,90분위264,553초로 짧은 세션 내 반복과 긴 재방문을 섞은 분포다.

완전한 마지막 UTC 날짜인9월17일까지 후속 관측이 가능한 첫 관측 ID만 사용하면, 이후 날짜의1/7/28일 내 재방문 비율은 각각 **2.766% / 5.847% / 8.652%**다(분모1,401,695 / 1,346,473 / 1,151,479). 첫 관측은 가입일이 아니며 좌측 검열과 쿠키 ID≠실제 사람 문제는 남는다. 같은 날짜의 재방문은 이 날짜 기준 지표에 포함하지 않는다.

**분석 정정:** 최초 audit.json의 재방문 분모는 마지막 부분 날짜까지 완전 관측으로 취급했다. 해당 출력은 보존하고 retention_followup_check.py 및 retention_complete_followup.json에서 완전 날짜 기준으로 바로잡았다. 본 문서의 재방문 수치는 정정값이다. 주간 프로파일·정책 입력에는 영향이 없다.
