# Retailrocket V2-C 재검증 사전 명세

2026-10-31. 정책 성과 실행 이전 고정. 자료 사용 판정은 research/activity_20261031/DATA_USAGE_GATE.md, 시간 해석은 TIME_TRANSFER.md를 따른다. 실측 한국 시각 및 인과 효과 검증이 아니다. 결과에 따른 계수·위상 선택 금지.

## 엔진과 활동

audit-fix-v1의 입찰, 재입찰, 스나이핑, WTP, 예산, 정산, 이벤트 처리 및 유사상품 포기 규칙을 그대로 상속한다. 새 코드는 주간 활동 공급 어댑터와 외생 방문 후보 스트림, 판매자 기본 종료 시각 결합, 정책에 한정한다. 기준 엔진 원본은 수정하지 않는다.

주 프로파일은 학습12주/평가7주의 요일×시간 평균 고유 활동 visitor ID이다. 168개 셀 평균1, 주말 효과를 다시 곱하지 않는다. 개인의 기존 hour_offset은 같은 요일 안에서 시간 열을 이동시키는 기존 의미를 유지한다. 전체 위상 이전은 주간 배열 전체를 이동한다.

개인 활동 기간의 시간 적분 J(기존 유효 주간 곡선), I(신규 곡선)를 구해 alpha=J/I로 organic visit rate만 조정한다. 이는 시장 두께가1일 때 예상 방문 수를 보존한다. 시장 두께 및 실제 유한 난수 때문에 실현 방문 총량은 달라질 수 있으므로 별도 보고한다. I=0,J>0이면 실행 실패로 처리하며 임의 평활화하지 않는다. 대조군은 개인별 보정 대신 주간 평균만 맞추는 global 방식이다.

기존 계획된 재방문/알림/스나이핑 가용성 규칙 activity/peak는 유지하되 주간 프로파일의 월–금 최대를 기준 peak로 일반화한다(ASSUMED). 이렇게 해야 기존 주말 배수 곡선을 입력할 때 원래 가용성과 정확히 대응한다. 계획 이벤트 가용성만 기존 곡선에 고정하는 진단도 둔다. 쇼핑 이벤트를 입찰로 전환하지 않는다.

기존 후보 cap을 초과하는 새 활동률을 자르지 않는다. 사전 정의된 모든 실제 프로파일·정규화 조건을 지배하는 cap으로 공통 Poisson 후보를 생성한다. seed/buyer/독립 namespace를 사용하고 모든 정책·조건에서 공유한다. 기존 후보의 난수로 다른 World 구성 요소를 다시 뽑지 않는다. 이 계산용 envelope는 추천기에 전달되지 않는다. 원래 후보를 사용한 legacy 결과18개는 동결 해시와 대조한다.

판매자 기본 종료와 구매자 활동의 상관은 원래 follow/crowded/uniform 생성 규칙을 재사용하여 유지한다. 원 World 생성 중 _default_end 호출 전 RNG 상태·명목 기간을 추가 난수 없이 기록한다. 기존 판매자 선호 시각의 CDF 구간 내부에 seed/seller별 고정 보조 분위수를 부여하고 새 활동의 평균 시간 곡선에 같은 생성 규칙을 적용한다. 원래 기간과 minute jitter를 재생한다. 이는 관측된 Retailrocket 판매자 행태가 아닌 기존의 ASSUMED 결합이다. 미래 실제 곡선으로 모형의 외생 판매자 모집단을 구성하더라도 추천기 입력에는 전달하지 않는다. 상관 제거는 uniform 선호 시각의 별도 진단이다.

## 정책

manual, uniform_valid, activity_only, competition_only, combined. 원 V2-C의 후보 생성(등록+24~72h,30분,97개), TOP3 간격180분, 심야00~05시 회피, 판매자 선택(원래 기본 시각에 가장 가까운 후보, 동률 이른 시각)을 공통 적용한다. uniform_valid는 같은97개 중 심야를 제외한 후보에서 단일 시각을 균등 선택한다. 수동 기준선의 원래 종료 시각은 보존한다.

**실행 전 제약 보정:** 기존 무작위 정책의 심야 무제약을 그대로 옮겼던 setup-v1은 사용자 요청의 동일 제약에 맞지 않았다. smoke-1과 main-1의 부분 출력·소스를 archive/setup-v1에 대응시켜 보존하고 최종 추론에서 제외한다. 무작위 단일 시각은97개 중 심야를 제외한 유효 후보에서 균등 추출한다. 원래 수동 시각은 기준선이므로 바꾸지 않는다. TOP3의 간격·선택 규칙은 세 추천 정책에 공통 적용한다. 성과 수치를 보고 변경한 것이 아닌 제약 불일치 수정이다. 새 smoke-2를 통과한 main-2만 최종 평가에 사용한다.

TOP3 점수는 a*log(A60)-c*log1p(C60), (a,c)=(1,0),(0,1),(1,1), beta=1,gamma=0 고정. 60분 삼각 커널·유사도는 기존과 동일하다. 세 정책 모두 같은 전역 greedy TOP3를 사용한다. 동률은 이른 시각으로 통일한다. 기존의 '가장 가까운 경쟁 경매까지 거리' 동률 해소는 활동 단독에 경쟁 정보가 새는 문제 때문에 세 정책에서 제거한다. 기존 conservative의 기간 구간 분할과도 다르다. 이 변경과 실측 곡선 변경을 혼동하지 않도록 old-policy bridge를 둔다. 점수의 관측 근거는 제한적이며 최적 가중치라고 주장하지 않는다.

추천은 과거 프로파일과 이미 등록된 공개 상품·종료 시각만 받는다. 미래 경매/입찰/낙찰/개인 WTP·예산 접근 금지. aligned는 평가 기간 곡선을 추천에도 준 oracle 진단이다.

## 고정 실험

기본 시드1~5, A~F,5정책. 기타 진단은 시드1~3이다. 독립 표본 단위는 seed이며 시나리오/주/경매 수로 표본 수를 늘리지 않는다.

- lagged: train UA→evaluation UA, A~F,1~5.
- aligned, old-shape control, flat control: A~F,1~3.
- input_error ±3,±6,12h: B,C,D,F,1~3.
- phase +3,+6,+9,+12,+15,+18,+21h(0=기본): B,C,F,1~3. source timezone 가설의 위상 조건이며 최선 위상 선택 금지.
- weak peak(0.5W+0.5flat), heldout week0~6, view prior, transaction prior, training top0.1% 제외: B,C,F,1~3.
- adoption20%, seller decoupled: B,C,D,F,1~3.
- frozen planned availability, global-only normalization: B,C,F,1~3.
- old-policy bridge: old shape A~F,1~3에서 기존 activity/conservative 정책. 활동 프로파일이 모든 시나리오에 동일해지는 실험이므로 기존 시나리오의 flat blend는 원 World 대조군에만 보존한다.

실제 heldout week별 조건은 각 주의 정규화된 형태를 30일 모형에 반복 적용하는 변동 스트레스이며 실제 49일 연속 실험이 아니다. 원래 horizon 및 World는 변경하지 않는다.

## 지표·추론·검증

일차: 등록당 낙찰 거래액(유찰0), combined−activity_only의 seed 대응 차이. 판매/유찰률, 경매당 입찰자, 시장 전체 거래액,20%채택의 채택/미채택 집단별 거래액 변화, 종료 시각·기간·자정 통과 이동, organic/planned 방문량도 보고한다. supply/proximity는 추천 시점 관측 변수로 층화하되 경매를 독립 추론 단위로 삼지 않는다.

시나리오별 대응 seed 차이와 Student-t 95% 구간(df=n_seed−1), A~E는 seed 안에서 시나리오를 동일 가중 평균한 뒤 구간, F는 별도. 작은3~5seed와 다중 진단의 한계를 명시하며 여러 구간 중 유의한 것만 선택하지 않는다. 입력 곡선 오차는 TV/MAE로 별도 측정한다. day/week 활동 불확실성은 자료 분석의 bootstrap2000회 결과를 사용하고 seed 불확실성과 섞지 않는다.

소규모 통합시험(프로파일·정보제약·정규화·cap·보존·쓰기/읽기/분석 경로)을 먼저 통과시킨다. 본 실행은 모든 시장의 불변조건, 기본150개 정책 결과와 나머지 seed1 조건의 완전 재실행 상태 동등성을 확인한다. 기존18개 결과의11CSV 해시를 재검증한다. RNG/heap 전체 추적은 별도 작은 진단에서 확인한다. 기계 시간은 검증 포함 실행비용으로 보고한다.

판정: 경쟁의 추가 가치가 가정 전반에서 안정적이지 않으면 경쟁을 성과 근거로 내세우지 않는다. 시간 추정 오차에 취약하거나 외부 타당성이 없으면 자동 대체 보류·실험용 TOP3로 제한한다. 유리한 결과를 위해 모델/가중치/위상을 재보정하지 않는다.
