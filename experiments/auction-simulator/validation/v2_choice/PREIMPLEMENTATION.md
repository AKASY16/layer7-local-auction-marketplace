# V2-B 사전 실험 명세 — known-surplus-v1

2026-10-31, 구현과 새 실험 전에 고정한 명세다. 기존 분석 결과는 알고 있으며 사전 등록 연구라고 부르지 않는다.

## 선택 모형

실제 view에서만 경매 i의 마지막 조회 정보 `(q_i, e_i, t_i, v_bi)`를 저장한다. q는 최소 필요 입찰가격, e는 그때 보인 현재 종료 시각, v는 기존 함수가 생성하는 고정 개인 WTP다. 실제 자신의 입찰 응답에서도 자신의 가격·종료 정보만 갱신한다. 다른 경매의 최신 상태는 무료 조회하지 않는다.

```text
F_b = budget_b − spent_b − committed_b
U_bi = v_bi − q_i
J_bi(t) = 이미 본 j≠i 중
          본 시각≤t, 마지막으로 본 종료>t,
          아직 소유하지 않고 선두도 아닌 것,
          q_j≤F_b, v_bj>q_j, s_ij>0,
          정보 유효기간 τ를 지정한 경우 t−t_j≤τ
R_bij = s_ij × (v_bj − q_j)
```

현재 경매가 기존 WTP·예산 진입 조건을 통과하지 못하면 기존 실패 판정을 그대로 사용한다. 통과하면 U>0일 때만 입찰을 고려하고, J 안에 현재 U보다 큰 R이 있으면 현재 입찰을 보류한다. 점수가 같으면 **알고 있는 종료가 빠른 것**, 다시 같으면 경매 ID가 작은 것을 택한다. 종료 차이에 비례한 벌점·보너스는 없다. 새 사건·자동 이동·가격 갱신은 만들지 않는다. 통과 후의 early/incremental/sniper·watch·재입찰·availability·proxy·정산은 기존 코드 그대로다.

선두인 현재 경매는 기존처럼 `already_leading`이다. 이미 선두인 다른 상품은 약정 예산에, 낙찰받은 상품은 이미 지출한 예산에 반영하며 새 대안과 섞지 않는다. 소유를 이유로 구매 수량을 1로 제한하거나 고유 WTP를 차감하지 않는다. 추가 구매는 남은 예산과 새 선택 판정으로 가능하다.

## 근거와 가정

- 자료가 뒷받침하는 방향: 경매 간 이동·불완전 탐색의 존재. 이 수식을 추정한 자료는 없다.
- **ASSUMED:** 현재/마지막 필요가를 사용하는 근시안 비교, 유사도를 대안 순이익의 관련성 배수로 쓰는 것, 즉시 조회 시 고정 개인 가치를 아는 것, 자기 입찰 응답·약정·정산 정보를 아는 것, 동점 해소, 보유 상품의 한계가치를 별도로 차감하지 않는 것.
- WTP 함수·분포·예산·방문·노출·스타일·유사도 입력은 그대로다. 신규 행동 난수·충돌 벌점·WTP 증가·외부 대안의 이중 차감은 없다.
- 새 선택식은 1개다. 유일한 추가 수치 설정은 가격 정보 유효기간 τ다. 주 실험은 **무제한(알고 있는 마감까지)**, 민감도는 **60분·360분**이다. 값을 결과에 맞춰 바꾸거나 가장 좋은 설정을 기본값으로 고르지 않는다.

## 검증·평가 고정

- A–F × seed1–3의 동일 World·기본 hard-close 정책. legacy 18회, 주 모형 18회와 동일 조건 재실행18회, 두 τ 민감도 각18회. V2-A 전체 observer를 사용하지 않고 비교에 필요한 카운터만 기록한다.
- legacy 선택은 동결 audit CSV198개와 정확 일치해야 한다. V2-B 두 반복은 부모 상태·선택 정보·기록·CSV·난수/큐 서명이 일치해야 한다. legacy와 V2-B의 사건 차이는 동등성 실패가 아니다.
- 예산·WTP cap·최소 입찰·시간·조회 정보·자기 정산·World 불변을 검사한다. 필수 위반은 모형 기각이다.
- 실측 오류는 같은 정의·조건부 표본으로 계산할 수 있는 외부 통계에만 제시한다. J&S 재입찰 홀드아웃을 주 참고, B-04는 같은 신품·기간 범위의 경매당 입찰자·판매율을 **시장 이전 진단**으로 사용한다. A-01 이동과 가격 분포는 노출 기간·상품 구성·단위가 달라 직접 정답으로 맞추지 않는다. 비교 불가능하면 오차 칸을 비운다.
- B-03/B-04 관측은 한 근거 계열이다. 둘을 독립 검증으로 세지 않는다. 시나리오 간 같은 seed도 독립 표본18개로 세지 않는다.
- 원시 USD·KRW 가격 수준은 비교하지 않는다. 기존 가격 log 표준편차 대리 목표는 범위를 밝힌 보조 진단이며 채택 근거의 실측 정답이 아니다.
- 모든 필수 검사 통과만으로 채택하지 않는다. 재입찰·참여·이동·판매·가격의 교환관계, 시나리오·seed별 안정성, τ 민감도와 추가 가정을 함께 보고한다. 일부 지표 악화가 크거나 비교 가능한 실측 근거가 부족하면 **보류/수정**한다. 종료 추천 정책 성과는 평가·최적화하지 않는다.
