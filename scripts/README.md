# 지역 시드 데이터 생성

## 원본

- 출처: https://www.code.go.kr/stdcode/regCodeL.do
- 다운로드 메뉴: 법정동 코드 전체자료
- 다운로드 날짜: 2026-10-08
- 파일: `data/법정동코드 전체자료.txt`
- 인코딩: CP949
- 형식: 탭으로 구분된 법정동코드, 법정동명, 폐지여부

## 변환 규칙

- 폐지여부가 `존재`인 행만 사용
- 읍·면·동·리와 시도 자체의 행 제외
- 시·군·자치구 단위로 저장
- 일반구는 제외하고 부모 시의 행 사용
- 세종특별자치시는 시도명과 시군구명에 같은 이름 사용
- 법정동코드 앞 5자리를 region_code로 사용
- 강원 51, 전북 52 코드 확인
- 지역 코드 중복 검사 후 코드 순서대로 출력

## 실행

프로젝트 최상위 폴더에서 실행:

```powershell
py scripts/generate_regions.py
```

결과:
`backend/src/main/resources/db/migration/V2__seed_regions.sql`

현재 원본 기준으로 지역 230개를 생성합니다.
같은 원본으로 실행하면 같은 SQL이 생성됩니다.

이미 DB에 적용한 V2는 수정하지 않습니다.
향후 지역 데이터 변경은 새 Flyway 마이그레이션으로 반영합니다.
